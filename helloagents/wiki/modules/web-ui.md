# Web UI 模块

## 目的
提供世界级“静态管理台”体验基线：高可读性、强层级、微交互与响应式布局，并支持导入快照数据进行离线展示。

## 模块概述
- **职责:** 视觉系统（Design Tokens）+ 信息架构（IA）+ 交互（Micro-interactions）+ 快照导入
- **状态:** ✅可用（持续迭代）
- **最后更新:** 2026-01-01

## 最近变更（摘要）
- 新增深/浅色主题切换（记忆偏好）。
- 快照导入后计算并刷新：入住率、到店/离店、房态总览、收入曲线。
- 支持一键导出 Markdown 日报，并提供 toast 状态反馈与快捷键。

## 规范
- 不引入前端框架与运行时依赖；保持纯静态可打开。
- 导入逻辑仅在本地解析文件，不触发网络请求。
- 保证可访问性：语义结构、键盘可用、焦点可见、对比度满足 WCAG AA。
