# Roadmap（演进路线）

> 目标：在保持“核心领域层稳定”的前提下，逐步扩展交互层（CLI → API → UI）与业务能力。

## 里程碑 0.x：骨架完善（当前阶段）

- 数据库可迁移（`user_version` + 幂等迁移）
- CLI 可脚本化（`--json`）
- 报表/导出（收入统计、CSV 导出）

## 里程碑 1：入住/退房与房态（建议优先）

- 入住（check-in）：记录实际入住时间、入住人核验
- 退房（check-out）：结算与释放房态
- 房态看板：按日期查看“空房/在住/将到/将离/维修”

## 里程碑 2：账单（Billing）

- 房费：按房晚计费（支持房价变更与历史快照）
- 折扣：会员/活动折扣
- 税费：按比例/固定税
- 发票信息与导出

## 里程碑 3：接口层扩展

- REST API（FastAPI/Flask 等可选，但建议保持领域层不依赖框架）
- Web UI（管理端 Dashboard）
- 权限系统（仅当需要多用户/多角色时引入）

## 里程碑 4：工程化与可观测性

- 更严格的静态检查与格式化（lint/format/type-check）
- 更完善的 CI（跨平台、打包校验、发布自动化）
- 结构化日志与审计轨迹（尤其是写操作）
